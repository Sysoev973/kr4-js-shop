# Исток — магазин тематических сборников источников

Многостраничный HTML/CSS-сайт на основе проекта [FBR](https://github.com/Sysoev973/FBR) (дисциплина «Фронтенд и бэкенд разработка», 3 семестр, 2026/2027).

## Автор
ФИО: Сысоев Георгий Михайлович
Группа: ЭФБО-10_25

## Тематика
Товар магазина — **тематический сборник источников** (книги, статьи, исследования) по конкретной теме.
Карточка сборника: название, тематика, краткое описание, список источников, цена.
Первая витрина — раздел **Engineering → AI Engineering**; первый сборник построен на базе курса [microsoft/AI-For-Beginners](https://github.com/microsoft/AI-For-Beginners).

## Референс стиля
Визуальное направление — [triforceproject.com](https://triforceproject.com): минимализм, акцентная serif-типографика, сдержанная «бумажная» палитра (чернила + ржавчина), волосяные линии. Демонстрационный характер референса адаптирован под продажу сборников: карточки с ценами, кнопки «Заказать», каталог, форма заявки.

## Как посмотреть проект
Сборка и сервер не нужны: проект состоит из статических файлов. Клонируйте репозиторий и откройте `index.html` в браузере.

## Структура проекта
```
responsive-shop/
├── index.html      — главная: hero, преимущества, популярные сборники
├── catalog.html    — каталог: 8 сборников, статический блок фильтров
├── category.html   — раздел Engineering: сборники и таблица сравнения
├── product.html    — сборник «AI Engineering: базовый сборник»: состав, таблицы, отзывы, FAQ
├── order.html      — форма заявки
├── contacts.html   — контакты и форма обратной связи
├── sitemap.xml     — карта сайта
├── css/style.css   — все стили (переменные, БЭМ, Flex/Grid)
├── js/main.js      — только открытие/закрытие модального окна
├── images/         — SVG-обложки сборников
├── README.md
└── .gitignore
```

## Используемые технологии
HTML5, CSS3 (переменные, Flexbox, Grid, sticky/fixed), минимальный JavaScript для `<dialog>`, Git. Без CSS-фреймворков.
